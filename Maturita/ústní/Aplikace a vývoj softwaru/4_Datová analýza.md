**Definice:** Proces při kterém se snažíme z dat vytvořit informace, které pak prezentujeme.

---

### Fáze datové analýzy

1. **Zadání** — definice cíle, co chceme zjistit
2. **Analýza zadání** — plánování postupu
3. **Sběr dat** — získání dat ze zdrojů
4. **Čištění dat** — odstranění chyb, duplicit, prázdných hodnot
5. **Samotná analýza** — hledání vzorů, statistiky
6. **Prezentace** — vizualizace, reporty, dashboardy

---

### Zdroje dat

- **Interní** — data která firma sama generuje (databáze, CRM)
- **Externí** — data z venku
    - Státní/veřejná data — ČSÚ, data.gov.cz
    - Sběr od klientů — formuláře, ankety, cookies
    - Web scraping — automatické stahování dat z webů
    - Senzory a IoT — měření teploty, pohybu, spotřeby
    - Sociální sítě — API
    - Nelegální získání — úniky dat, hacking

### Formáty dat a strojová čitelnost

**Strojová čitelnost** — vlastnost dokumentu, jak dobře ho dokáže zpracovat stroj. Strojově čitelná data mají jasnou strukturu.

| Formát   | Čitelný | Použití                     |
| -------- | ------- | --------------------------- |
| CSV      | ANO     | tabulková data              |
| JSON     | ANO     | web, API                    |
| XML      | ANO     | konfigurace, starší systémy |
| PDF      | NE      | dokumenty pro lidi          |
| JPEG/PNG | NE      | obrázky                     |
| DOCX     | NE      | textové dokumenty           |

> Hranice se dnes posouvá díky AI — obrázky a text lze strojově zpracovat pomocí modelů.

---

### Otevřená data

Data která splňují tyto podmínky:

- **Volně dostupná** — kdokoliv k nim má přístup
- **Legálně použitelná** — open licence, lze je použít, sdílet, upravovat
- **Strojově čitelná** — ve formátu CSV, JSON, XML — ne PDF nebo obrázek
- **Zdarma** nebo za minimální poplatek
- **Bez diskriminace** — dostupná komukoliv

Příklady v ČR: **data.gov.cz**, **ČSÚ**, **OpenStreetMap**
